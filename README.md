# 하루 플래너

할 일, 바뀐 일정, 갑자기 생긴 일정을 관리하고 AI가 하루 타임라인에 자동 배치해 주는 웹앱입니다.
아침식사 여부에 따라 기상 알람 시간을 자동으로 계산합니다.

## 기능
- **기상 알람 자동 계산**: 첫 일정 − 이동 − 준비 − (아침식사) = 기상 시간. 날짜별로 아침식사 여부를 켜고 끌 수 있습니다.
- **AI 자동 배치**: 고정 일정 사이 빈 시간에 할 일을 중요도·마감 기준으로 배치합니다 (Claude API).
- **갑자기 생긴 일정**: "오후 3시에 팀플 회의 1시간"처럼 문장으로 입력하면 AI가 해석하고, 겹치는 할 일을 다시 배치합니다.
- **바뀐 일정**: 일정 시간을 수정하면 '변경됨'으로 표시하고 겹친 할 일을 옮깁니다.
- **아이폰 앱처럼 사용 (PWA)**: Safari → 공유 → 홈 화면에 추가.

## 구조
- `index.html` — 앱 화면 (데이터는 기기의 localStorage에 저장)
- `api/ai.js` — Vercel 서버리스 함수. `ANTHROPIC_API_KEY` 환경 변수로 Claude API 호출
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA 설정

## 배포
- **GitHub Pages**: 화면만 동작하고, AI 대신 규칙 기반 자동 배치가 쓰입니다.
- **Vercel**: 이 저장소를 가져오고 `ANTHROPIC_API_KEY`를 환경 변수로 넣으면 AI 기능까지 동작합니다.
